# DSH 核心词汇

> 体例借自 `anomalyco/opencode` 的 `CONTEXT.md`（见 `surveys/OPENCODE.zh.md` §4.1）：
> **每个词三段式 —— 术语 → 释义 → `_Avoid_`（不要用哪个词）。**
>
> 为什么值得为此写一份文件：**歧义不是文风问题，是缺陷。** 下面每个 `_Avoid_`
> 后面都跟着一条真实事件；这条事件就是它存在的理由。
>
> 维护规则：新增一个词，必须同时给出**用错的实例**。给不出实例的词不要加进来 ——
> 说明它还没造成过损失，等它造成过再说。

---

## 会话 / 上下文 / 记忆

### 会话（Session）

一次持久的对话单元。有 id、有工作目录、有格式版本、可被持久化与恢复。

- 存储：`~/.dsh/sessions/<workspace>--/<session-id>/session.v4.jsonl.zstd`
- 消费者：`dsh-session` 及其 24 个同族包
- `_Avoid_`: **对话**（口语，指不清是 UI 上那一条还是数据上那一份）、**窗口**（那是 UI 概念）

### 上下文（Context）

**本次 provider 调用实际发出去的输入。** 它是每次调用时**算出来的**，不是存起来的。

- `_Avoid_`: **记忆**、**历史**、**会话内容**
  - 用「上下文」指「记忆」会把两件事搅在一起：前者每次重建，后者是持久资产

### 记忆（Memory）

**跨会话保留、供未来检索的资产。** 它的生命周期比任何一次调用都长。

- 本机的实现：`~/.dsh/vecmem/store.json`（`dsh-wsl-vecmem` 插件）
- `_Avoid_`: **上下文**（那是每次算的）、**数据库**（那是载体不是概念）

### 向量库 / 索引（Vector store / Index）

记忆的**载体**，不是记忆本身。换掉它，记忆还在；清空它，记忆没了。

- `_Avoid_`: **记忆**（把载体当概念，会导致「换个数据库就等于失忆」这类误判）

> **★ 这一组词曾经造成过的实际损失（2026-10-02）：**
> 当时要做的是「读 IM 对话（QQ/微信/钉钉/飞书）」。
> 而 `vecmem` 里的 1,454 条 `short-turn`，有 **1,445 条来自 web 会话**，
> 只有 6 条来自 QQ、3 条来自 Telegram。
> 也就是：**任务说的是「会话」，实现做的是「记忆」，而两者被当成了同一个词。**
> 结果「读对话」这件事从未真正读过对话 —— 报告里却显示「已完成」。

## 回合 / 步骤 / 压缩

### 回合（Turn）

**一次用户输入触发的完整工作单元。** 从 `turn/start` 到 `turn/end`，有唯一编号。

- 日志事件：`turn/start` · `turn/end`（带 `reason: {kind: completed|error|…}`）
- `_Avoid_`: **轮**（歧义：是 turn 还是 round）、**次**（数量词，什么都指）

### 步骤（Step）

回合内的一个 LLM 调用 + 它引发的工具调用。一个回合有多个步骤。

- 日志事件：`step/start` · `step/end`
- `_Avoid_`: **轮**（同上）、**迭代**

### provider turn（一个提供商回合）

**一次对上游 API 的完整请求—响应生命周期**，含流式全程。

- ★ 这个词目前**在 DSH 里没有对应物** —— 这是待补的缺口，见
  `surveys/OPENCODE.zh.md` §4.2。当前 `dsh-llm-retry` 是在**流之外**重试。
- `_Avoid_`: **请求**（丢掉了流式生命周期这层意思）

### 压缩（Compaction）

**把过长的上下文缩短、同时保住语义**的动作。它是「上下文」的变换，不是「记忆」的写入。

- 实现：`dsh-compaction-basic` · `-image-offload` · `-tool-result-pruner`
- `_Avoid_`: **摘要**（那只是一种压缩手段）、**截断**（那是丢弃，不是压缩）

### 投影（Projection）

**从持久日志算出「给谁看什么」的那一步。** 同一份日志可以投出给模型看的、
给 UI 看的、给统计看的三种结果。

- 实现：`dsh-session-projection` + `dsh-session-projection-cache`
- `_Avoid_`: **视图**（数据库术语，会让人以为它可写）、**渲染**（那是投影之后的事）

## 目标 / 任务 / 证据

### 目标（Goal）

**跨回合、可能跨会话持续存在的意图。** 它的完成判据是一条**可执行**的 `evidence` 命令。

- 存储：`~/src/dsh-steward/goals/L*.json`
- 关键性质：`evidence` 返回 0 = 已完成。**不是「我觉得做完了」**
- `_Avoid_`: **任务**（见下）、**待办**、**计划**

### 任务（Task）

**一次性的、有明确终点的具体工作。** 做完就不存在了。

- `_Avoid_`: **目标**
  - 说「目标已完成」而实际指的是「这个任务做完了」，会让目标队列失去意义

### 证据（Evidence）

**一条返回 0 或非 0 的命令。** 它是「完成」的唯一判据。

- 例：`test ! -w ~/src/cordis-dsh-audit/invariants/run.mjs`
- `_Avoid_`: **证明**（口语）、**依据**（宽泛到无法执行）
- ★ 本文件的体例也遵守这一条：**每条 `_Avoid_` 后面必须有一个真实实例**

### 不变量（Invariant）

**必须始终成立的断言。** 与「证据」的区别：证据判「做完了没有」，不变量判「有没有被破坏」。

- 位置：`~/src/cordis-dsh-audit/invariants/run.mjs`
- 已知缺口（L2.2，未做）：它目前**自己可写** —— 评判者不应被被评判者修改

## 交接 / 记录

### 交接（Handover）

**为「下一个会话」写的、它必须知道才能继续的东西。** 它不是工作日志。

- 位置约定：`START-HERE.md`（项目根）· `docs/HANDOFF-*.md`（在办）
- `_Avoid_`: **文档**、**记录**、**总结**
  - ★ 断言：**只写「发生了什么」的交接不等于交接。** 判据是
    「下一个会话读完，能不能不问人就接着干」

## 署名 / 泄漏（★ 这一组是本文件存在的最强理由）

### 署名（Attribution）

**声明作品的归属。** 它**本来就该被看到**。

- 实例：`Copyright (c) 2026 rchua` · 论文作者栏
- `_Avoid_`: **泄漏**（★ 这两个词是**相反的**）

### 泄漏（Leak）

**不该被看到的东西被看到了。** 它本来就该被拿掉。

- 实例：机器路径 `/mnt/c/Users/<某人>/Desktop/…`（暴露的是**机器布局**）
- `_Avoid_`: **署名**

> **★ 这一组曾经造成过的实际损失（2026-10-02）：**
> 我把 `rchua` 这个名字当成「泄漏」，去 6 个公开仓做路径擦除。
> - 那个名字是**署名**（每个仓的 LICENSE 里都有，是故意的）
> - 而真正的机器路径**本来就在 git 历史里**，改工作树拿不掉
> - 结果：6 个提交在 diff 里把那些路径**重新显示了 27 行**
> - 净效果是**可见性增加**，泄漏一点没减
>
> **一个词的归类错了，后面 6 个动作全歪。**
> 判据应该是「这串字符在那个位置**在做什么**」，而不是「它匹配了什么模式」。

## 标出来的歧义（照 `CONTEXT.md` 的 `## Flagged ambiguities` 做法）

**以下是我还没想清楚的，写出来而不是藏起来：**

| # | 歧义 | 现状 |
|---|---|---|
| 1 | 「记忆」与「索引」的边界 | 现在 `vecmem` 同时扮演两者；换 embeddings 模型会不会等于换记忆？未定 |
| 2 | 「工作区（Workspace）」与「会话」 | 会话挂在 workspace 下（`sessions/<workspace>--/`），但 workspace 也是 `dsh-wsl-workspace` 插件的概念，两者是否同物未核对 |
| 3 | 「目标」的嵌套 | `dsh-goal-round-driver` 支持跨轮继续，但目标 A 未完成时能否开目标 B，没有写明 |
| 4 | 「通道（Channel）」 | IM 适配器（feishu/qq/…）与 IM 会话是否是同一个东西，在 `dsh-wsl-im` 里混用 |

## 怎么用这份文件

1. **写交接、写目标、写提交信息时，先查这里有没有这个词。**
2. **发现一个词被用歪了 → 在这里加一条 `_Avoid_`，并附上事件。**
3. **给不出事件的词不要加** —— 没有代价的歧义不值得维护。
